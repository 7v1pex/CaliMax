# CaliMax

Trainings-App für Calisthenics und Gym als Web-App (PWA).

- Öffne die Seite auf dem Handy und füge sie zum Home-Bildschirm hinzu.
- Alle Daten bleiben auf dem Gerät (localStorage und IndexedDB).
- Die Übungsvideos in `videos/` sind eigene Animationen.
- Die Sprachaufnahmen in `audio/` (Calisthenics) wurden mit ElevenLabs erstellt.
